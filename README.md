# Couloir 14

منصة وموقع لتنسيق الاستجابة لحوادث المرور في الجزائر العاصمة. مشروع طلابي لهاكاثون SolveX 3.0. لم يُجرَّب في تدخل حقيقي، ولا يتحكم في أي ضوء حقيقي.

الواجهة بالفرنسية، ما عدا صفحتي الشاهد `/l/:token` و`/app` ورسالة SMS له، فهي بالعربية لأنها موجهة لعامة الناس.

## التشغيل
يحتاج Node.js 24 أو أحدث، ولا يحتاج قاعدة بيانات منفصلة.

```bash
npm install
npm run vendor
npm start
```

ثم افتح `http://localhost:8080`. في أول تشغيل يُنشأ ملف `.env` برموز دخول عشوائية للعون والطاقم والمستشفى. لا ترفعه إلى GitHub.

```bash
npm test
```

## الصفحات
| الصفحة | لمن |
|---|---|
| `/` | الصفحة التعريفية (الإحصائيات الرسمية، المشكلة، المسار، فريق العمل) |
| `/login` | دخول العون أو الطاقم أو المستشفى |
| `/dispatch` | عون الحماية المدنية (مركز التنظيم والتحكم 14) |
| `/unit` | طاقم الإسعاف (واجهة الهاتف المحمول) |
| `/er` | مصلحة الاستعجالات بالمستشفى |
| `/metrics` | لوحة تحكم المسؤول (تحليل أزمنة المراحل، وتحديد أسباب التأخر، والنشاط اليومي) |
| `/l/:token` | الشاهد، عبر رابط لمرة واحدة لتحديد الموقع والصور |
| `/app` | تطبيق البلاغ الاختياري للمواطنين |
| `/twin` | صفحة محاكاة التوأم الرقمي (SUMO 1.28) |

## الإعدادات في `.env`
| الإعداد | المعنى |
|---|---|
| `OPERATOR_PIN`, `CREW_PIN`, `HOSPITAL_PIN` | رموز الدخول |
| `SESSION_SECRET` | مفتاح توقيع الجلسات |
| `PUBLIC_URL` | الرابط الذي يُرسل في SMS، ويجب أن يكون `https` ليعمل GPS على الهاتف |
| `SMSGATE_USERNAME`, `SMSGATE_PASSWORD` | حساب SMS Gateway for Android. بدونهما يظهر الرابط ورمز QR على الشاشة |
| `DEMO_SPEED_MS` | سرعة السير المحاكى في العرض بالمتر في الثانية، والافتراضي 30 |
| `OSRM_URL` | خادم حساب الطرق |

## التجربة من هاتف حقيقي
لا يعطي المتصفح الموقع إلا عبر HTTPS. فإما أن تنشر المشروع على خادم Node.js بقرص دائم، أو تفتح نفقاً من جهازك مثل Cloudflare Tunnel، ثم تضع الرابط في `PUBLIC_URL` وتعيد التشغيل.

## كيف بُني
- `server/rules.js`: القواعد القابلة للاختبار: الخطورة، قاعدة 8%، الدمج، الأضواء أمام الإسعاف.
- `server/app.js`: سلوك المنصة وما يراه كل طرف.
- `server/adapters.js`: الاتصال بالخارج: SMS، والطرق، والأضواء.
- `server/index.js`: الصفحات والجلسات والصلاحيات والتحديث الحي.
- `public/`: الشاشات.

## ما هو محاكاة أو غير مكتمل
- **الأضواء:** `createSimulatedController` لا يصل إلى أي ضوء. والمتحكم الحقيقي يطبق نفس الدالتين، ويجب أن يلتزم بـ`docs/signal-controller.md`.
- **الطرق:** خادم OSRM التجريبي، بحد طلب واحد في الثانية ودون ضمان ودون حركة مرور حية. إذا تعذر، يُستعمل تقدير بخط مستقيم وتقول الشاشة ذلك.
- **البيانات الأولية:** المواقع من OpenStreetMap وتجب مراجعتها، وأغلب الأضواء افتراضية.
- **جدول الخطورة:** مقترح، ويجب أن تراجعه الحماية المدنية.
- **الدخول:** رمز لكل دور، وهذا يكفي للعرض لا للاستعمال الحقيقي. قبله يلزم حساب لكل مستخدم.
- **العمل دون اتصال:** الأحداث التي تقع أثناء انقطاع إنترنت الطاقم لا تُحفظ لإرسالها لاحقاً.
